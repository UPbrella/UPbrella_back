# 로그인 세션 유지와 회원 조회 보호

운영 프로필은 Spring Session JDBC에 세션을 저장하고 30일 쿠키/세션 만료를 사용합니다. 쿠키는 Secure·HttpOnly를 유지합니다. 배포 전 `src/main/resources/db/26_2_persistent_session.sql`을 선택한 DB에 한 번 적용해야 합니다. 운영 시작 시 스키마를 자동 생성하지 않습니다. 기존 메모리 세션 사용자는 최초 전환 시 다시 로그인합니다. home-dev는 별도 프로필 PR에서 활성화합니다.

로그인 확인은 세션과 실제 회원 존재를 확인하고 401을 반환합니다. 운영진 권한은 DB의 현재 값을 확인하여 권한 회수 후에도 이전 세션으로 접근하지 못하게 합니다. 회원 조회 시 복호화한 은행/계좌 값은 응답용 객체에만 넣어 JPA 변경 감지로 평문이 저장되는 것을 막습니다.

검증: 인터셉터 단위 테스트, 회원/본인 정보 조회 후 flush·clear 및 암호문 보존 회귀 테스트. 운영 DB나 기존 데이터는 이 PR 준비 과정에서 변경하지 않았습니다.
