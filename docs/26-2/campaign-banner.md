# 배너 및 스탬프 투어

배포 전 `src/main/resources/db/26_2_campaign_banner.sql`을 적용하고 `upbrella.uploads-directory`에 영구 저장 볼륨을 설정합니다. PNG/JPEG 5MB, 2천만 화소 이내 업로드를 지원하며 활성/기간/순서에 맞는 배너만 공개합니다. 삭제는 논리 삭제입니다.

스탬프는 기본 비활성입니다. 활성 기간의 최초 대여, 기한 내 반납(사용자당 1회), 설문(사용자당 1회)에 지급합니다. 회원 잠금과 고유 지급 키로 중복 지급을 막습니다. 우천 미션·알림톡·스마트 리턴은 포함하지 않습니다. 관리자 설정과 지급 목록/CSV를 제공합니다.

인증 기반 PR 이후 적용하는 후속 PR입니다. 운영 DB·실제 회원 또는 캠페인 활성 상태는 PR 준비 중 변경하지 않았습니다.
