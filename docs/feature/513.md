# Feature #513: 우산 상태 세분화 및 재고 정리

## 개요

우산 상태를 대여 가능/불가능(`rentable`, `missed`)에서 네 가지 상태(`status`)로 나눈다. (26-2 결정사항 [우산 관리 탭])

| status | 의미 | 대여 |
|--------|------|------|
| `AVAILABLE` | 사용 가능 | 가능 |
| `RENTED` | 대여중 | 불가 (대여중 예외) |
| `UNLOCATED` | 위치 미확인 | 불가 (분실 예외) |
| `LOST` | 분실 | 불가 (분실 예외) |

- 대여하면 `RENTED`, 반납하면 반납 지점에서 `AVAILABLE`이 된다. 위치 미확인·분실 우산도 반납되면 사용 가능이 된다.
- 지점별 대여 가능 개수(앱 지도, 지점 상세)는 `AVAILABLE`만 센다.

## 하위 호환

FE가 `status`로 옮기기 전에도 지금처럼 동작하도록 기존 필드를 남겼다. FE가 옮기면 지운다.

- **DB**: `rentable`, `missed` 컬럼을 남기고 `status`가 바뀔 때 같이 바꾼다. (`rentable` = 사용 가능, `missed` = 위치 미확인 또는 분실)
- **응답**: 우산 목록에 `status` 추가, `rentable`은 `status`가 `AVAILABLE`이면 true.
- **등록 요청**: `status`가 없으면 `rentable`로 정하고, 둘 다 없으면 `AVAILABLE`.
- **수정 요청**: `status`가 없으면 `rentable`/`missed`로 정하고, 셋 다 없으면 상태를 바꾸지 않는다.
- 기존 값(`rentable`/`missed`)은 예전 통계와 같은 상태로 옮긴다.

| rentable | missed | status |
|----------|--------|--------|
| true | false | `AVAILABLE` |
| false | false | `RENTED` |
| (상관없음) | true | `LOST` |

## 통계 응답

| 필드 | 의미 |
|------|------|
| `rentableUmbrellaCount` | 사용 가능 |
| `rentedUmbrellaCount` | 대여중 |
| `unlocatedUmbrellaCount` | (신규) 위치 미확인 |
| `lostUmbrellaCount` | (신규) 분실 |
| `missingUmbrellaCount` | 위치 미확인 + 분실 (기존 필드, 기존 FE의 "분실 우산 개수"에 이 값이 보인다) |
| `missingRate` | 위치 미확인 + 분실 비율(%) |

상태별 개수는 `GROUP BY status` 쿼리 한 번으로 센다. (기존에는 상태마다 행을 전부 불러와서 셌다)

## 배포 순서

운영 DB에는 `ddl-auto`가 없어서 컬럼을 직접 추가해야 한다.

1. 머지 전: `src/main/resources/db/513_umbrella_status.sql` 실행 (`status` 컬럼 추가 + 기존 값으로 채우기)
2. 머지 → 맥미니 자동 배포
3. 배포 직후: `src/main/resources/db/513_umbrella_status_sync.sql` 실행. 1~2 사이에 예전 코드가 `rentable`/`missed`만 바꾼 우산을 `status`에 반영한다. 여러 번 실행해도 된다.

## 재고 정리 (운영진 목록을 받은 뒤)

`src/main/resources/db/513_umbrella_cleanup.sql`

- 9/27 기준 배치 우산(목록)에 새 관리번호(1~30)를 준다. 반납 안 된 대여가 있으면 대여중, 아니면 사용 가능.
- 목록 밖 우산은 마지막 대여일(대여 기록이 없으면 등록일) 기준 3개월 이내면 위치 미확인, 넘으면 분실. 반납 안 된 대여가 있어도 결정사항대로 분류한다.
- 새 관리번호와 겹치는 목록 밖 우산은 가장 큰 관리번호 뒤로 옮긴다.

## 하지 않은 것

- 3개월 기준을 주기적으로 자동 적용하지 않는다. 운영진이 원하면 별도로 스케줄러를 만든다.
- 위치 미확인 우산을 사용자가 매장에서 찾아 대여하려 해도 막힌다. (기존 분실 우산과 같음)
